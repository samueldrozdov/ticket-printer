# Deploy from GitHub

The current GitHub → Raspberry Pi workflow is documented in
[DEPLOYMENT.md](DEPLOYMENT.md). Push a tested commit, install that exact revision
on the Pi, restart the app, and verify it in a refreshed browser.

This file previously described a separate Netlify frontend. That is not the
current Samson installation; see [legacy Netlify notes](README_NETLIFY.md) for
the remaining configuration files and limitations.
